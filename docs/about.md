The `create-ds-projects` project is a `command-line tool` designed to streamline the creation of data science projects.

## Description

It provides a structured **template** that includes essential components such as

### Features

- directories for data,
- notebooks,
- scripts, and
- documentation.

This tool aims to help data **scientists** and **analysts** quickly set up their projects with best practices in mind, ensuring consistency and efficiency in their workflow.

## Constraints

**The tool is designed to run on Linux and macOS systems.** It may not be compatible with Windows environments without additional configuration or tools like **WSL (Windows Subsystem for Linux)**.
