# User Manual

This is the user manual for the `create-ds-projects` tool.

## Installation

To install the `create-ds-projects` tool, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/ChristianSchinkel/create-ds-projects.git
   ```

2. Navigate to the project directory:

   ```bash
   cd create-ds-projects
   ```

3. Make the script executable:

   ```bash
   chmod +x src/scripts/main.sh
   ```

## Usage

To use the `create-ds-projects` tool, run the following command from the project directory root or navigate to the `src/scripts` directory and execute the script:

```bash
src/scripts/main.sh [options]
```

### Options

- `-h`, `--help`: Show help message and exit.
- `-n`, `--name`: Specify the name of the project.
- `-d`, `--description`: Provide a description for the project.
